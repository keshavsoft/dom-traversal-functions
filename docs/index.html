dom-traversal-functions

Standardized, instruction-driven DOM traversal and data extraction utilities organized around the 3-part semantic story of the table: Header, Body, and Footer.

GitHub Repository → Interactive Demo ↓
1. Header Concern
Search & Controls

getSearchQuery(el) extracts, trims, and normalizes search inputs via declarative instructions.json.

2. Body Concern
Rows & Actions

getRowElement, getRowIndex, highlightRow, and getRowData cleanly traverse table rows without fragile selectors.

3. Footer Concern
Entry & Clearing

getFooterData captures new records from footer inputs, and clearRowInputs resets them cleanly for the next entry.

Usage in Your Code
import { table } from "https://keshavsoft.github.io/dom-traversal-functions/dist/v3/min.js";

// Header
const query = table.header.getSearchQuery(searchInput);

// Body
const rowData = table.body.getRowData(button, { columns: [{ columnName: "itemName" }] });
table.body.highlightRow(button, "table-primary");

// Footer
const newRow = table.footer.getFooterData(saveBtn, columns);
table.footer.clearRowInputs(saveBtn);
